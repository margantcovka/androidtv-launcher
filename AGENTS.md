# Правила для агентов

С пользователем общаться только по-русски.

- Это нативный лаунчер для Android TV / Google TV: Kotlin + Jetpack Compose for TV,
  без WebView. Образец дизайна — tvOS и
  [HarshInvader/webos-launcher](https://github.com/HarshInvader/webos-launcher) (MIT);
  код оттуда не копируем, переносим идеи.
- Всё, что анимируется, — через `graphicsLayer` (масштаб, прозрачность) или готовые
  картинки. Живой blur и тяжёлые эффекты на весь экран не использовать: GPU телевизоров
  слабый.
- Обработка картинок (баннеры, размытие, цвета краёв) — один раз при загрузке, в `data/`,
  не в composable.
- Размеры в dp под экран 960×540 dp (1080p TV), все токены в `ui/Tokens.kt`.
- Новые зависимости — только если без них никак.
- Проверка изменений UI: собрать `./gradlew assembleDebug`, поставить на эмулятор `gtv36`
  (см. README), пройти сценарий кнопками `adb shell input keyevent …` и посмотреть
  скриншоты. Сборка без ошибок ещё не значит, что экран выглядит правильно.
- Ничего не делать с телевизором пользователя (ADB-команды, отключение системных
  приложений) без его явного согласия на конкретное действие.
- Удалённый репозиторий — `origin` (GitHub, публичный): в коммиты и файлы не класть ничего личного.
